# 家庭现金流与评估口径

## 模型链路

问卷输入经过类型、范围、分支与互斥关系检查后，转换为计算记录。养老金模型分别处理本人和配偶的参保历史、退休时点及养老账户；家庭模型再将养老金、资产和收支组织到统一的月度计算中。

六类金融资产为现金及活期、定期存款、基金、股票、债券和保险现金价值。保费累计不自动等同于保险现金价值。受限养老账户缴款从自由资金扣除，有限账户耗尽后停止支付。

模型先推演退休前的工资、支出与资产积累，再按成员各自退休规划期计算养老资源。退休后的情景比较将各成员领取期与共同价格口径对齐；该对齐后的月份序列用于准备充足程度比较，不能直接当作夫妻在同一自然月份的实际到账记录。

## 四类情景

基本生活和常规医疗情景主要比较养老金资源与对应支出。重大疾病及失能照护情景计入风险折扣后的金融资产本金和资产收入，分别加入重疾压力与照护成本。本金在对应情景资源中只计一次。

情景覆盖指标为`可用资源 / 情景所需`。指标与月度可支配收入回答不同问题：一个衡量规划期内的覆盖，另一个描述选定口径下的月度预算。

## 参数

地区和养老金参考数据位于`core/data/pension-parameters.json`；其余经济假设位于`core/parameter_data.py`及`core/parameters.py`。公开版本保存研究使用的参数快照，不自动更新政策。

退休前支出按2%增长，工资增长等假设及资产收益率均可在源码和结果中查看。退休后比较采用共同价格口径，有限账户按余额约束支付。未知收入或资产会触发项目定义的估计规则，结果中的`default_parameters`和`low_confidence_fields`记录相应信息。

## 可复核输出

`calculations.json`包含养老金构成、资产与费用拆分、家庭月度路径、情景分子分母和评分。`report.json`引用同一份计算结果。建议与解释不回写计算金额。

项目基线来自退休准备评估核心源码交付版，源文件校验值见[source_manifest.json](source_manifest.json)。公开实现将宿主平台依赖替换为独立运行接口，并增加输入适配、离线报告和测试。
